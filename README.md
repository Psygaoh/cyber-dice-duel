# Cyber Dice Duel

An asymmetric tactical browser game about a Runner breaching a corporate network while the Corp deploys ICE to stop the intrusion.

Custom dice generate actions and unfold into six-cell network paths. The Runner controls one agile Avatar and builds backdoors; the Corp controls several slower ICE units and secured infrastructure.
